# Primitive consensus test fixtures

- `bip340.csv`: all official BIP340 signature test vectors, including invalid encodings and variable-length messages, retrieved 7 October 2026 from https://raw.githubusercontent.com/bitcoin/bips/master/bip-0340/test-vectors.csv. Specification and vector provenance: https://bips.dev/340/.
- `asert-run01` through `asert-run12`: the complete twelve official ASERT integer difficulty test runs, retrieved 7 October 2026 from https://download.bitcoincashnode.org/misc/data/asert/test_vectors/. Specification and linked fixture provenance: https://bitcoin-cash-node.gitlab.io/bchn-sw/bitcoincash-upgrade-specifications/2020-11-15-asert/.
- `transaction-current.hex` and `.sha256d`: an independently packed transfer record and its SHA256d, checked against the documented field order in `tests/codec_vectors.rs`.
- `transaction-signing.json`: a chain-bound signing vector for a conditional PASS deposit: secret key 0x2a repeated, its public key, a chain ID, the canonical body, its message `tagged_hash("Hashstash/chain-bound-transaction", chain_id || body)` computed directly with Python's `hashlib`, and the BIP340 signature with zero auxiliary randomness from the soak harness's signer (itself checked against `bip340.csv`). `tests/transaction_signing_vector.rs` checks it against the node's signing message, libsecp256k1 and verification; `scripts/test_soak.py` and the soak's startup self-test check the harness against it.
- `grant-current.hex`: an independently packed two-recipient grant: tag 0, count 2, the public x coordinates of G and 2G, and amounts 258 and 65,537 encoded as minimal little-endian magnitudes. It contains no signatures or live account data.

The tests use the published expected results directly. They do not generate expected results with the implementation under test. Hashstash applies the same ASERT integer algorithm to its cumulative schedule error instead of Bitcoin Cash's constant-spacing height schedule. The Bitcoin genesis header test in `src/codec.rs` checks the original mainnet header and block hash documented in Bitcoin Core's `src/kernel/chainparams.cpp`.
